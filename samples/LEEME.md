# Pack de FX para Mixxx (gratis)

Carpeta: `dj-fx-pack/` — **39 sonidos** (WAV + MP3).

Origen: [ClubDJ Pro Free FX Pack](https://www.clubdjsoftware.com/free-dj-sound-effects) — royalty-free, uso en directo/streaming.

## Qué incluye

- `fx-airhorn.mp3`, `fx-foghorn.mp3` — bocinas
- `vocal-are-you-ready-*.mp3` — voces
- `riser-*.wav`, `sweep-*.wav`, `downlifter-*.wav` — transiciones
- `impact-*.wav`, `sub-drop-*.wav` — drops
- `drum-*.mp3/wav` — percusión
- Ver `dj-fx-pack/CREDITS.txt` para licencias

## Cómo usarlos en Mixxx

1. Abre Mixxx → **Ver → Sampler**
2. Arrastra archivos de `dj-fx-pack/` a los pads **S1, S2, S3…**
3. En directo, pulsa el pad: suena en la emisión

## Volver a descargar

```bash
cd samples
curl -L -o pack.zip https://clubdjsoftware.com/clubdjpro/packs/clubdjpro-free-fx-pack.zip
unzip -o pack.zip -d dj-fx-pack && rm pack.zip
```
