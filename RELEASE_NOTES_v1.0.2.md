# Release v1.0.2

## 🎉 Nuevas Características

### Interfaz de Usuario
- **Lista de usuarios ocultable**: Ahora puedes ocultar completamente el panel de usuarios del canal para tener más espacio en el chat. El panel se puede mostrar/ocultar desde un botón en el AppBar o desde un botón flotante cuando está oculto.
- **Foco automático en campo de texto**: Al presionar Enter y enviar un mensaje, el foco vuelve automáticamente al campo de texto, permitiendo escribir el siguiente mensaje sin hacer clic.

### Sistema de Actualizaciones
- **Verificación manual de actualizaciones**: El badge de versión ahora es clickeable y permite verificar manualmente si hay actualizaciones disponibles. Muestra un indicador visual mientras verifica.
- **Mejoras en la visualización**: La versión ahora aparece junto al botón de estado de conexión en el AppBar para mejor accesibilidad.

### Radio
- **Nueva estación**: Añadida "Radio Sonic Frequency" a la lista de estaciones disponibles.
- **Mejoras en la reproducción**: Mejorado el soporte para streams de `listen2myradio.com` con múltiples variantes de URL y headers específicos.

## 🔧 Mejoras

- **Logo del background**: Actualizado el año de copyright a 1999-2026.
- **Videoconferencias y audioconferencias**: Mejoras en la detección automática de invitaciones privadas y apertura automática del navegador.
- **Mensajería**: Mejoras en el envío inmediato de mensajes con Enter.

## 📦 Instalación

1. Descarga el archivo `irc_app_macos_v1.0.2.dmg`
2. Abre el DMG y arrastra la aplicación a la carpeta Applications
3. Ejecuta la aplicación desde Applications

## 🔄 Actualización desde versiones anteriores

Si ya tienes una versión anterior instalada:
1. Descarga el nuevo DMG
2. Reemplaza la aplicación antigua con la nueva versión
3. La aplicación detectará automáticamente futuras actualizaciones
