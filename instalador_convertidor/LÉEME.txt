📦 INSTALACIÓN
═══════════════════════════════════════════════════════════════════

1. Arrastra la aplicación "Convertidor M4A a MP3" a tu carpeta 
   Aplicaciones

2. Abre la aplicación desde tu carpeta Aplicaciones

3. Si macOS te pregunta sobre seguridad:
   - Ve a Preferencias del Sistema → Seguridad y Privacidad
   - Haz clic en "Abrir de todas formas"

4. La primera vez que abras la aplicación, te preguntará si deseas
   instalar FFmpeg (necesario para convertir archivos)
   - Haz clic en "Instalar FFmpeg"
   - Sigue las instrucciones en pantalla

🚀 CÓMO USAR
═══════════════════════════════════════════════════════════════════

Es muy fácil:

1. Abre la aplicación "Convertidor M4A a MP3"

2. Elige una opción:
   
   📄 ARCHIVOS INDIVIDUALES
   - Selecciona uno o varios archivos M4A
   - La aplicación los convertirá a MP3
   
   📁 CARPETA COMPLETA
   - Selecciona una carpeta
   - Convertirá todos los archivos M4A que encuentre
   
   🎬 YOUTUBE → MP3/M4A (NUEVO!)
   - Ingresa la URL de un video de YouTube
   - Elige el formato (MP3 o M4A)
   - Selecciona dónde guardar el archivo
   - La aplicación descargará y convertirá el audio automáticamente

3. ¡Espera a que termine!
   - Verás notificaciones del progreso
   - Los archivos se crearán en la carpeta seleccionada

❓ PREGUNTAS FRECUENTES
═══════════════════════════════════════════════════════════════════

P: ¿Qué es FFmpeg?
R: Es una herramienta gratuita que hace la conversión de audio.
   La aplicación te ayudará a instalarlo automáticamente.

P: ¿Qué es yt-dlp?
R: Es una herramienta para descargar videos de YouTube y otras
   plataformas. La aplicación te ayudará a instalarlo automáticamente
   cuando uses la función de descarga desde YouTube.

P: ¿Se borran mis archivos M4A originales?
R: No, los archivos originales se mantienen intactos. Solo se
   crean nuevos archivos MP3.

P: ¿Dónde se guardan los archivos MP3?
R: En la misma carpeta donde están los archivos M4A originales.

P: ¿Qué calidad tienen los MP3?
R: Alta calidad - 320kbps (la mejor calidad para MP3).

P: ¿Puedo convertir muchos archivos a la vez?
R: Sí, puedes seleccionar múltiples archivos o una carpeta
   completa.

P: ¿Puedo descargar videos de YouTube?
R: Sí, ahora puedes descargar el audio de videos de YouTube
   directamente. Solo ingresa la URL y elige el formato (MP3 o M4A).

P: La aplicación no se abre
R: Ve a Preferencias del Sistema → Seguridad y Privacidad
   y haz clic en "Abrir de todas formas"

🐛 SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════

Si tienes problemas:

1. Asegúrate de tener macOS 10.13 o superior

2. Si FFmpeg o yt-dlp no se instalan automáticamente:
   - Abre Terminal (en Aplicaciones → Utilidades)
   - Copia y pega este comando:
     /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   - Después ejecuta:
     brew install ffmpeg yt-dlp
   - Vuelve a abrir la aplicación

3. Si los archivos no se convierten:
   - Verifica que los archivos M4A no estén dañados
   - Asegúrate de tener espacio en disco
   - Verifica que tengas permisos de escritura en la carpeta
